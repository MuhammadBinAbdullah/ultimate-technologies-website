ULTIMATE TECHNOLOGIES WEBSITE

FILES
- index.html: website sections and content
- style.css: responsive styling, logo treatment, cloud animation, and effects
- script.js: role rotation, mobile navigation, admin preview editor, social links, contact form
- assets/ultimate-technologies-logo.png: supplied logo

HOW TO OPEN
1. Extract ultimate-technologies-website.zip.
2. Open the ultimate-technologies folder.
3. Double-click index.html to preview it in your browser.

ADMIN EDITOR PREVIEW
- Click ADMIN LOGIN in the top navigation.
- Demo password: UT-Admin-2026!
- After unlocking, click outlined text to edit it.
- SAVE TEXT downloads an edited HTML copy. Replace index.html with that downloaded copy to keep the text edits (keep style.css, script.js, and the assets folder beside it).

BEFORE PUBLISHING
- The password is only a front-end demo. Anyone can inspect the JavaScript and discover it. Real admin-only access requires server-side authentication and saving changes through a protected backend/CMS.
- In script.js, replace YOUR-EMAIL@example.com with the official contact email.
- Add actual YouTube, Instagram, and Facebook profile URLs in SOCIAL_URLS.
- The contact form currently prepares a mailto message only after the official email is configured; it does not send/store messages on a server.


EDIT SAVING NOTE
The admin editor now saves editable text in the current browser and restores it when the site is reopened in that browser. Bright/dark mode preference is saved too. This is local browser storage, not server publishing.
